# Satya_Gummuluri

Satya Gummuluri marvels at how anyone relates to anything or anyone at all. What are you talking about? What's happening? How do you know for sure? How are you so sure? Things like that. There are so many questions to be asked, to be considered, to be examined. What is it i show? What is it you hide? What are we thinking? And what about memory? Memories by definition are networks of impressions undergoing erasure, one only distortedly recollects the memory of a memory. So what is this soup we swim about in, how do we find our way? This questioning is sometimes gratuitous, sometimes purposeful, sometimes pathological. 

Her questions surface as words, sounds, music and images.
